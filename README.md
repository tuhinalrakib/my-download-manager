# StreamPull - YouTube Video & Audio Downloader 🎥🎵

একটি সেরা এবং সুবিধাজনক ইউটিউব ভিডিও এবং অডিও ডাউনলোড করার সফটওয়্যার। যেকোনো ইউটিউব ভিডিওর লিংক দিলেই তা থেকে ভিডিও (1080p HD, 720p, 480p) বা অডিও (MP3) ডাউনলোড করা যাবে।

---

## 🚀 কীভাবে চালু করবেন (How to Run)

### পদ্ধতি ১: ১-ক্লিকে চালু (সহজতম উপায়)
১. সফটওয়্যার ফোল্ডারের ভেতর থাকা **`run.bat`** ফাইলটিতে ডাবল ক্লিক করুন।
২. এটি প্রয়োজনীয় প্যাকেজ ইনস্টল করে নিজে থেকেই ব্রাউজারে **`http://localhost:5000`** ওপেন করবে।

---

### পদ্ধতি ২: ম্যানুয়ালি কমান্ড দিয়ে চালানো
১. আপনার টার্মিনাল বা Command Prompt ওপেন করুন।
২. ডিপেন্ডেন্সি ইনস্টল করুন:
   ```bash
   pip install -r requirements.txt
   ```
৩. সার্ভার চালু করুন:
   ```bash
   python app.py
   ```
৪. আপনার ব্রাউজারে গিয়ে **`http://localhost:5000`** লিংকটি ভিজিট করুন।

---

## ✨ ফিচারসমূহ (Features)

- 🔗 **যে কোনো লিঙ্ক সাপোর্ট**: সাধারণ ইউটিউব ভিডিও, YouTube Shorts এবং Music লিঙ্ক।
- 🖼️ **ভিডিও প্রিভিউ**: লিঙ্ক পেস্ট করলেই ভিডিওর থাম্বনেইল, শিরোনাম, চ্যানেল নাম ও ভিউ দেখা যাবে।
- 🎬 **ভিডিও কোয়ালিটি অপশন**: 1080p Full HD, 720p HD, 480p সহ বিভিন্ন কোয়ালিটি পছন্দ করার সুবিধা।
- 🎵 **অডিও এক্সট্রাকশন**: ভিডিও না চেয়ে শুধু MP3, M4A বা WAV অডিও ডাউনলোড করা।
- ⚡ **লাইভ প্রোগ্রেস**: রিয়েল-টাইমে ডাউনলোডের স্পিড, বাকি সময় (ETA) এবং প্রোগ্রেস বার।
- 📁 **সহজ ডাউনলোড**: ডাউনলোড শেষ হলে সরাসরি পিসিতে ফাইল সেভ করার অপশন।
